# Стрелок

2D рикошет-шутер. Попади в цель через рикошеты от стен!

## Играть онлайн

**https://destian1995.github.io/Shooter/**

Открой ссылку в браузере на компьютере или телефоне.

## Запуск локально

### Способ 1 — Просто открыть файл

Открой `index.html` в браузере (Chrome, Firefox, Edge). Всё работает без сервера.

### Способ 2 — Локальный сервер (для PWA и Service Worker)

```bash
# если есть Node.js
npx serve .

# если есть Python
python -m http.server 8000
```

Затем открой `http://localhost:3000` (или `http://localhost:8000`).

## Установка на Android

1. Открой **https://destian1995.github.io/Shooter/** в Chrome на телефоне
2. Нажми **⋮ → Добавить на главный экран**
3. Игра установится как приложение — полноэкранная, с иконкой, работает оффлайн

## Управление

- **Зажми** экран/кнопку мыши — прицеливание (появится линия траектории)
- **Отпусти** — выстрел
- Пуля рикошетит от стен и пробивает несколько целей

## Особенности

- Случайная генерация уровней с проверкой проходимости
- 5 типов целей: обычные, бронированные, движущиеся, мигающие, взрывные
- 9 прокачек: рикошеты, урон, скорость, выстрелы, мультишот, пробивание, прогноз, крит, магнит
- Ударная волна от урона — цепные убийства
- Бонусы: двойное убийство, рикошет x4, супер рикошет x7, комбо
- Цвет снаряда меняется с прокачкой (серый → жёлтый → красный → оранжевый → зелёный → синий → фиолетовый)
- Монетки на уровне, множитель дохода
- Таблица рекордов
- Фон эволюционирует с прогрессом — от спокойного к динамичному

## Технологии

HTML5 Canvas, чистый JavaScript, без зависимостей. PWA-ready.
